# پارس پینگ (ParsPing)

اپلیکیشن اندروید تغییر DNS بدون نیاز به روت، با نمایش پینگ زنده برای هر DNS
(از جمله DNSهایی که خودتان اضافه می‌کنید) و یکپارچه‌سازی تبلیغات ادیوری.

## نحوه باز کردن پروژه

1. Android Studio (نسخه Hedgehog به بالا پیشنهاد می‌شود) را باز کنید.
2. Open → پوشه `ParsPing` را انتخاب کنید.
3. صبر کنید تا Gradle Sync کامل شود (اولین بار ممکن است چند دقیقه طول بکشد
   چون Android Studio باید Gradle 8.5 و وابستگی‌ها را دانلود کند).
4. Run را بزنید (روی گوشی واقعی تست کنید؛ VPN روی اکثر امولاتورها هم کار می‌کند
   ولی گوشی واقعی برای تست پینگ واقعی بهتر است).

> نکته: فایل باینری `gradle-wrapper.jar` در این پروژه نیست (چون این محیط به
> اینترنت دسترسی نداشت). خود Android Studio هنگام Sync آن را می‌سازد؛ اگر
> ساخت نشد، از منوی Android Studio گزینه‌ی
> **File → Sync Project with Gradle Files** یا **"Upgrade Gradle Wrapper"**
> را بزنید.

## معماری تغییر DNS (بدون روت)

به‌جای گرفتن همه ترافیک اینترنت داخل یک VPN واقعی (که باید همه بسته‌ها را
دوباره مسیریابی کند)، این اپ فقط **مسیرهای Host (/32) برای IP همان DNS
انتخابی** را داخل تانل VPN قرار می‌دهد (`ParsPingVpnService.kt`). یعنی:

- فقط بسته‌هایی که به IP سرور DNS انتخابی می‌روند وارد تانل ما می‌شوند.
- بقیه‌ی ترافیک (وب، بازی، هر اپ دیگر) دقیقاً از همان مسیر شبکه واقعی رد
  می‌شود و اصلاً وارد تانل نمی‌شود.
- داخل تانل هم فقط لازم است بسته‌ی UDP:53 گرفته‌شده را با یک سوکت
  `protect()`‑شده به همان سرور DNS واقعی بفرستیم و پاسخ را در قالب یک بسته‌ی
  IPv4/UDP به تانل برگردانیم (`PacketUtils.kt`).

این یعنی سربار شبکه و ریسک باگ بسیار کمتر از یک VPN کامل با فورواردینگ
TCP/UDP عمومی است، و دقیقاً همان ترفندی است که اکثر اپ‌های واقعی
"DNS Changer بدون روت" استفاده می‌کنند.

## یکپارچه‌سازی تبلیغات ادیوری

- `App.kt`: `Adivery.configure` + گرم‌کردن هر دو تبلیغ‌گاه در همان ابتدا.
- `MainActivity.showAppOpenAdOnLaunch()`: تبلیغ «بازگشت به برنامه» را همان
  لحظه‌ی باز شدن اپ نمایش می‌دهد (اگر آماده نبود، منتظر بارگذاری می‌ماند).
- `MainActivity.showRewardedThenConnect()`: وقتی کاربر روی «اتصال» می‌زند،
  اول تبلیغ جایزه‌ای نمایش داده می‌شود؛ فقط اگر `isRewarded == true` باشد
  (یعنی کاربر تا آخر دیده) اتصال VPN واقعاً برقرار می‌شود.

قبل از هرکدام از این دو، اجازه‌ی VpnService از سیستم گرفته می‌شود
(`VpnService.prepare`).

## چیزهایی که باید خودتان تنظیم کنید

- آیکون اپ فعلاً یک وکتور ساده‌ی سبز است (`res/drawable/ic_launcher.xml`) —
  اگر آیکون اختصاصی دارید جایگزینش کنید.
- کلیدهای ادیوری از قبل در `Constants.kt` گذاشته شده‌اند.
- لیست DNS پیش‌فرض در `data/DefaultDnsList.kt` است؛ به‌راحتی می‌توانید مورد
  اضافه/ویرایش کنید.
